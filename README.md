# 🚀 SmartCareer AI — Resume Optimizer & Mock Interview Platform

SmartCareer AI is an interactive React application designed to optimize resumes for Applicant Tracking Systems (ATS) and prepare candidates for technical interviews.

---

## ✨ Features

* 📂 **Resume Upload & Parsing**: Parse PDF structure and experience lines.
* 📊 **ATS Score Analyzer**: Direct match indexing against target job descriptions.
* 🎙️ **Adaptive AI Mock Interviews**: Live feedback loops based on identified gaps.
* 🗺️ **Learning Roadmaps**: Custom career path development steps.

---

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Run the local development server
npm run dev

# Build the production bundle
npm run build
```
